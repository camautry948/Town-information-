Municipal Finance & Payroll Resource Hub

Upload these files to the root of a GitHub Pages repository:
- index.html
- manifest.json
- sw.js

The app is static and does not store town/customer information.
External buttons open official government/retirement/training websites.

Reference data in this build was checked September 19, 2026.
Because tax and retirement rules change, confirm effective dates on the linked official source before changing payroll configuration.
